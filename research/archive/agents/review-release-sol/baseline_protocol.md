# Predeclared lightweight baseline — 2026-11-26
Written before computing baseline scores. This is not an ESM2 reproduction.

Data: primary==1, mutant==0 source kinetics; normalize surrounding/repeated whitespace in species labels; remove byte-equivalent observations ignoring the CSV index; collapse metadata duplicates; one median kinetic target per normalized species. Preserve named cultivars/strains as separate target observations, but link them in species groups using a conservative base-name rule: first two tokens for standard Latin binomials; preserve full Synechococcus numeric strain names. Manually avoid merging distinct bacterial strain names where full binomial plus strain is present by grouping them together (more conservative holdout). Metadata must map to exactly one unique sequence per normalized species; exclude ambiguous cases rather than choose using labels. Report this rule and exclusions.

Features: fixed amino-acid fractions (20), all ordered dipeptide fractions (400), sequence length (1). No pretrained model, alignment-derived features, or target-driven feature selection. StandardScaler fitted only on training fold; Ridge alpha=100 fixed; no PCA, hyperparameter search, or post-score changes. Control predicts the training mean of log10 target.

Validation: 5-fold group holdout repeated for seeds 0–9. Connected components join normalized base species and identical full sequences. Second, stricter stress test additionally joins sequence pairs with global alignment identity >=99%, defined as aligned identical residues divided by the longer full sequence length, using global alignment match=1 mismatch=-1 gap-open=-2 gap-extension=-0.5. This is a homology sensitivity test, not a phylogeny-independent benchmark. Random group ordering, greedy balancing by number of species, fixed across targets before dropping missing labels. Report group counts and overlap assertions. No group ever crosses train/test. No score-based split selection.

All six deposited kinetic targets evaluated on positive finite values after median aggregation, log10 scale. Primary challenge-related endpoints S and vC. Report pooled out-of-fold R2, RMSE, Spearman per repetition and mean/range across repetitions. For seed 0, 1000 paired component bootstrap draws of RMSE(model)-RMSE(mean), conditional on fitted OOF predictions; these do not include model refitting uncertainty. Repetition ranges measure split sensitivity, not independent confidence intervals. Do not use this baseline to estimate original-model leakage bias or to claim a challenge solution.
