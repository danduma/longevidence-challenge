Independent computational audit, 2026-11-26

The pinned public release is not a reliable stand-alone cross-species kinetic benchmark for choosing candidates against the Millennium Rubisco criterion. The deposited predictions support some rank signal for specificity and CO2 affinity, but contain repeated species and sequence overlap, use targets sensitive to unhandled whitespace, and fail to demonstrate useful absolute turnover prediction. The paper’s headline specificity score comes from an additional nested-CV output branch in Version3, not the fixed-parameter branch described by the current README. No original-model correction or bias magnitude is estimated here: the required Flamholz embeddings and their ordered IDs are absent. A separately predeclared, actually executed lightweight baseline shows useful specificity signal and weaker turnover signal under grouping, but does not validate the joint challenge objective.

This audit read only the specified source directory/archive and public paper/code/literature. It did not read root Rubisco analyses or other agents’ reports, modify shared inputs, call other models, contact anyone, or post externally. All generated files reside in this job directory. Methods, paths, links and failures are recorded below and in sources.md. No model refusal occurred.

Identifier, sequence and target audit

The source CSV has 634 observations; the shipped `primary==1, mutant==0` filter retains 504. These have 315 raw species strings and 308 after surrounding/repeated whitespace normalization. There are no exact duplicate source observations when the exported CSV index is ignored. There are 15 extra occurrences of source identifiers, which are not unique observation keys: repeated identifiers can represent separate kinetic fields, literature sources, temperatures or species. For example, `balearicum_galmes` refers to both Hypericum balearicum and Limonium balearicum. Blind identifier deduplication would lose information. The trace is retained in outputs/reused_source_identifiers.csv and outputs/wt_observation_trace.csv. Some mutation-bearing species names pass the nominal WT flags (e.g. Synechococcus 6301 F92L); these were not matched to the released sequence metadata and therefore do not enter this baseline. The flags alone are not a complete biological WT validator.

The metadata and FASTA each contain 214 records, 207 unique labels/species, and only 169 distinct full sequence strings. All repeated FASTA labels resolve to the same sequence; metadata sequence lengths agree with FASTA. Seven metadata rows and FASTA records repeat exactly: Flaveria angustifolia, F. bidentis, F. cronquistii, F. floridana, F. trinervia, Phaseolus vulgaris and Zea mays. These are seven extra records rather than seven independent enzymes. Distinct species also share identical released RbcL sequences: examples include five Aegilops/Triticum names, Sorghum bicolor/Saccharum officinarum, and Synechococcus 6301/S. elongatus PCC 7942. Identical RbcL does not prove identical holoenzyme kinetics; it does mean a sequence-only test row may have its entire sequence represented in training.

Cultivar handling also preserves multiple target labels for the same accession and sequence: Glycine max and G. max cv. Wayne both map to P27066; three Nicotiana tabacum/W38 strings map to P00876. Conversely, many explicit cultivar/strain spellings are not mapped at all. Treating raw species strings as biological independence is unjustified, while merging every cultivar into one phenotype would also discard real variation. The baseline preserves target observations and groups likely conspecific names together for splitting.

Seven unique sequences are shorter than 400 residues, including Capsicum annuum (P27063, 16 aa), Mercurialis annua (P31195, 54 aa), Atriplex glabriuscula (184), Polypodium aureum (184), Pistacia lentiscus (186), Medicago sativa (219), and Urtica membranacea (230). These lengths are measured facts about deposited inputs; I did not establish that each accession is taxonomically wrong. Such fragments cannot be assumed to describe full-length engineering candidates. The baseline keeps them as predeclared, so its results also retain this limitation. See outputs/short_sequences.csv and outputs/identical_sequence_species.csv. Species-to-UniProt association does not establish identity to the exact enzyme preparation assayed in the cited source, particularly for cultivars and small-subunit combinations.

The shipped scripts aggregate by raw `species` without stripping whitespace. Metadata is trimmed, whereas prediction outputs include trailing-space species. Every deposited `y_true` in both output branches equals log10 of the corresponding positive raw-species WT median; target transformation is therefore traceable, with no evidence here of arbitrary labels. But normalization changes scientifically relevant targets. Phaseolus vulgaris turnover is 1.7 in the trailing-space subset versus 2.6 after combining whitespace spellings; KC changes from 7.8 to 14.0. Zea mays S changes from 74.9 to 78.3 and KO from 157 to 483.5. Flaveria trinervia turnover changes from 4.42 to 3.85. These are differences in aggregation, not corrected experimental truths. Cultivar names are kept separate in these comparisons. Full row-level provenance is in outputs/target_provenance.csv.

There is a concrete reproducibility discrepancy. Literal raw-species aggregation and merging to the shipped trimmed metadata, with all 214 FASTA records in their deposited order standing in for embedding IDs, gives S n=177 and vC n=173, not 183 and 181. For all six targets, an alternative reconstruction exactly matches the deposited species order, row counts and y_true values: map each trimmed metadata name to the last matching raw spelling in the sorted source species list, retaining duplicate FASTA records, then perform the shipped merge. This is a historical-mapping reconstruction assumption, not a claim that the released scripts explicitly implement it or proof of the original embedding order. The pattern is consistent with earlier untrimmed metadata surviving in targets while metadata was later normalized. outputs/reconstruction_checks.csv records both the literal failure and the alternative exact matches. This inconsistency remains even before fitting a predictor.

The paper’s Table 3 values, S=0.753 and KC=0.605, match tune_stepA. Calling the README branch a failed reproduction of those headline values would conflate two deposited analyses. The paper also acknowledges weak performance of other traits; poor turnover performance is not an undisclosed new numerical discovery. The published table labels its statistic “Spearman Mean,” while the deposited nested summary is the pooled OOF correlation from a single default five-fold run; the files alone do not establish averaging over independent split repetitions. [Paper](https://www.mdpi.com/3042-6723/1/2/7).

Both scripts fit StandardScaler and PCA on training data inside their respective folds; that protection is present in code. Nested parameter selection is restricted to outer-training data. The default split is shuffled row-wise KFold, seed 0, after the species-to-embedding merge. Duplicated embedding records therefore reintroduce repeated species after the purported species aggregation. Neither default groups species nor sequences. The tuning script offers taxonomy GroupKFold, but tune_stepA summaries explicitly say `kfold`; that option does not demonstrate that it was used, and taxonomy grouping is not equivalent to grouping identical sequences.

Exact pair definitions and component construction are the same as the baseline protocol. Duplicate observations and sequence sharing are facts; exposure counts depend on the split assumptions. Potential optimistic bias and species weighting are concerns for independent generalization, but their magnitude and even direction in the original model are not identified by this audit. I did not refit that model or attribute the difference between its two branches to leakage.

A training-fold mean on the reconstructed default folds has turnover RMSE 0.1871, compared with 0.2732 fixed and 0.3333 nested. Negative deposited R2 already establishes performance worse than an overall observed-mean constant in squared error; the training-fold mean is a separate, deployable control under the split assumptions. Specificity beats this control (RMSE 0.1725). Rank association alone does not demonstrate reliable absolute threshold crossing. Executed corrected lightweight baseline

baseline_protocol.md was written before any baseline scores. The model is fixed sequence composition (20 amino-acid fractions, 400 ordered dipeptide fractions, sequence length), StandardScaler fitted on training folds only, Ridge alpha=100, no PCA and no tuning. Control is each training fold’s log10 target mean. This is not PLM representation reproduction. Source whitespace is normalized, exact source duplicates are removed ignoring the index (none found), metadata/FASTA duplicates collapse, and kinetic medians are computed once per normalized species. No ambiguous multi-sequence species required exclusion. There are 207 matched observations, with target-dependent missingness; 101 normalized WT species remain unmatched.

Five-fold splits repeat for seeds 0–9. Connected components link conspecific base names (first two whitespace-separated tokens, retaining numeric second-token strain names) and exact sequences; a stricter stress test additionally links global-alignment identity >=99%. Identity is number of identical aligned residues divided by longer full sequence length, with global alignment match=1, mismatch=-1, gap-open=-2 and gap-extension=-0.5. This avoids calling short fragment overlap full-length identity. Components and random group allocation are constructed without targets and shared across targets before dropping missing labels. All 207 observations form 169 exact/species components, or 129 with the 99% rule (largest 6 and 15). Every training/test split asserts species and exact-sequence separation. This protects the stated grouping rules, not every synonym, evolutionary relationship, study batch or holoenzyme component.

The table shows means over ten split seeds; brackets give the range across those seeds, not a confidence interval. All predictions and all six endpoints are saved in outputs/; no split or model was selected by its score.

|---|---|---:|---:|---:|---:|
| Species + identical sequence | S / 176 | 0.776 | 0.678 [0.641, 0.704] | 0.0990 | 0.1756 |

For seed 0, 1000 paired component bootstrap draws give RMSE(Ridge)-RMSE(mean) intervals of [-0.1158,-0.0464] for S and [-0.0390,+0.0122] for vC under exact/species grouping; the 99% stress-test intervals are [-0.1195,-0.0431] and [-0.0550,-0.0016]. These are conditional on existing OOF predictions, without model refitting; they do not quantify all training or dataset uncertainty. Repetitions share observations and are not ten independent biological replications. Pooled control Spearman can be negative because fold means vary; a constant within each test fold provides no within-fold ranking. KC also shows signal; KO and KRuBP remain weak, as detailed in outputs/baseline_summary.csv and outputs/baseline_bootstrap.csv.

This baseline supports the existence of sequence-related kinetic signal after the stated grouping corrections. It does not tell us how much the original model’s performance would change after correction: representation, target construction and splits differ. It remains a small heterogeneous benchmark containing fragments, a coarse species grouping rule and phylogenetic proximity below 99%. Stronger novelty-of-sequence or prospective discovery claims need curated sequence/assay linkage, phylogeny-aware evaluation and independent assays.

Relation to the Millennium criterion

The official criterion requires a single enzyme with specificity at least Galdieria partita and turnover at least maize, each measured in paired assays against the named control. KC affinity is not CO2/O2 specificity; DMS enrichment, Vmax proxies and growth cannot substitute for both purified-enzyme measurements. [Official criterion](https://millenniumproblems.bio/).

The source contains G. partita Tokara S=238 and vC=1.6 at 25 C, but no Galdieria sequence is matched in the benchmark. These source numbers are contextual observations, not universal challenge cutoffs. Baseline maximum observed median S is 225 (Cyanidium caldarium), below that source Galdieria value. The baseline has 148 observations with both S and vC, yet was evaluated separately on each endpoint; no held-out joint-success calibration or prospective candidate panel was attempted. Maize appears twice in metadata and with multiple whitespace/cultivar target spellings; its literature turnover values are about 4.05–4.1, again not substitutes for contemporaneous paired controls. Source medians can combine assays at different pH, temperature, expression context and publication; 487 of 504 WT rows are at 25 C, with others spanning -1 to 83 C, and pH is heterogeneous or missing. Scripts’ defaults do not condition on assay context. Therefore this release can motivate exploratory prioritization, but it cannot certify or reliably rank a shortlist for the required joint frontier without substantial curation and experimental validation.

Prior reporting and bounded novelty assessment

Search queries, dated links and retrieval limitations are in sources.md. The paper itself reports that some kinetic traits are difficult and discusses assay heterogeneity and small-subunit effects. The deposited turnover scores are therefore a checkable limitation, not a claim of novel criticism. Version3’s release description already mentions normalizing Flamholz metadata; it does not establish that the species merge, target spellings and repeated records were repaired. The all-state GitHub issues API returned only three closed PRs, concerning README/reproduction/revision tooling, with no entry documenting the specific repeated-record, whitespace target or fragment findings. The version-notes page lists a September HTML update without a defect-specific explanation. Searches combining the title/DOI/repository with duplicate, whitespace, leakage, fragment, correction and criticism found no identified prior specific audit of these defects. This is not proof that nobody reported them elsewhere.

The general scientific concerns are established. Flamholz et al. describe the restricted kinetic variation and biased sampling in the compendium; Bouvier et al. demonstrate phylogenetic structure; primary assay-method work documents intermethod variation. More recent identity-aware rate prediction already compares to mean controls. These precedents support the evaluation choices here without independently verifying defects in this release. [Flamholz 2019](https://doi.org/10.1021/acs.biochem.9b00237), [Bouvier 2021](https://doi.org/10.1093/molbev/msab079), [assay-method variability](https://academic.oup.com/jxb/article/72/22/7846/6331685), [identity-aware rate prediction](https://doi.org/10.1073/pnas.2501433122).

Reproduction and verification

Run `./run.sh` from this job directory using the specified scientific Python. It executes inspect_release.py, audit.py, baseline.py, supplemental_checks.py and verify_release.py; saved API evidence permits pin checks without a network refresh. fetch_evidence.py optionally refreshes public HTTP evidence. The complete baseline run stores 120 OOF prediction files (two grouping regimes × six targets × ten seeds), metrics, bootstrap summaries, groups, features recoverable from sequences, source hashes and package versions. Original Flamholz `flamholz_rubisco_esm2_t12_mean.npy` and its ordered ID manifest were not found in either supplied tree or Version3; no attempted original-model reproduction is claimed. Main-task embeddings, if elsewhere in the archive, would not solve the missing species-specific feature/ID mapping.

Fresh verification checks every deposited metric against its shipped summary, verifies all shared input hashes are unchanged, checks pinned Git blobs and archive checksum, and asserts grouping integrity during the actual baseline fit. Execution/package details are in outputs/environment.json and verification.log. HTTP failures and robot checks are in network_failures.md and web_evidence/retrieval_log.json; refusals.md records none observed. No claims here depend on treating a network failure as model behavior.
