# Frozen analysis protocol v1 — 2026-11-26

The scout report, its source inventory/scripts, paired-table headings, selected historical numbers, 2026 Table 1, and both independent release reports were inspected before this protocol. No source/control cycle tests or transfer scores have been computed here. This is a new retrospective analysis, not a prospective biological preregistration. File hashes and UTC timestamps will accompany execution. All changes will be documented as amendments before the affected analysis, or explicitly post hoc.

## Aim
Build a reusable measurement/control benchmark and test whether a single multiplicative study correction is sufficient to port historical Rubisco specificity and turnover comparisons. An additive log measurement model is log(y_es)=enzyme_e + source_s. A connected graph identifies relative offsets only under this model; loops provide falsifiable checks. Shared species are candidate bridge observations, never automatically certified common control preparations.

## Inputs and exclusions
Original 2019 workbook with original `use` and primary/mutant fields; preserve source identifiers and all raw values. Numeric historical analysis: primary, wild-type, `use=True`, exactly 25 Celsius, positive measured S or vC. No reconstructed kcat from growth, no error imputation, no temperatures converted. Retain separate traits, conditions and expression contexts. Whitespace normalization only for the main broad species bridge graph. Cultivar/strain strings remain distinct; audited aliases only in labeled sensitivity analyses. Strict control graph requires documented strain/cultivar/preparation comparability, temperature, pH, gas convention and measurement definition; missing metadata remains unknown. Zero errors are not treated as exact precision.

2026 kiag259: separate cohort; distinguish new measurements from numbers reused from prior publications using table typography/footnotes. Identify wheat table control and spinach specificity-method standard separately. Audit 1997 Galdieria, 2001 Griffithsia and 2008 maize anchors against corrected primary sources; unavailable source fields are not certified. 2025 corrected library stays a 30 Celsius coupled-assay cohort and supplies no measured specificity.

## Predeclared quantitative tests
1. For each trait independently, aggregate multiple accepted rows only within exact species × short_ref × pH group by geometric mean, reporting the member IDs; do not use cross-pH averaging in the primary cycle analysis. Source-condition node is study × recorded pH (including explicit unknown). Build bipartite incidence graph; record connected components, anchor reachability and cycle rank E−V+C. Repeat with species × study aggregation as a clearly weaker sensitivity analysis.
2. Enumerate all complete 2-species × 2-source rectangles in each trait graph. Define log cycle discrepancy d=log(y_a1/y_b1)−log(y_a2/y_b2). exp(abs(d)) is the factor by which relative enzyme comparisons change. Primary summary: counts, median and maximum factor, fraction above 1.1 and 1.25; preselected 10% and 25% tolerances are decision sensitivities, not confidence intervals. Report dependence; no p-value treating rectangles as independent.
3. Transfer benchmark: each rectangle supplies control-to-target transfers in both directions. For each direction compare raw ratio transport (source offset zero) to correction based on the other enzyme in the same rectangle. Errors are absolute log prediction error and RMS log error. Report all rectangles, source-pair aggregated scores, and leave-one-source-out sensitivity. These are conditional retrospective portability checks, not a model-discovery claim. Separate S/vC; do not select favorable traits/sources. Report direction and magnitude even if calibration fails.
4. If both endpoints and meaningful common controls are available for anchor comparisons, compute exact ratios within source and explicit chain products. Show pH/identity uncertainty and alternate paths. No calibrated joint enzyme success labels unless both controls/traits are genuinely paired under documented comparable conditions. Prove algebraic nonidentifiability when offsets/identity cannot be resolved.
5. Report uncertainty ONLY when primary error kind and sample count permit it; otherwise give observed discrepancy factors and sensitivity ranges. Do not treat 2025 shared correction uncertainty as independent per enzyme. No claims of physiological/chemical constraints or universal assay bias from cycles.

## Prior-art/novelty boundary and falsification
Assay variability, genus-held-out prediction, phylogenetic attenuation and ordinary control normalization are known. The contribution sought is a versioned, audited endpoint/control dataset and a quantitatively tested statement about which specific modern/historical comparisons survive control transport. Compare with 2025 corrected-rate/library papers/code, 2026 primary kinetics and relevant current design/prediction literature. No claim of novelty from absent search hits or toy algebra. A future independent same-preparation two-control assay can falsify a portability result; no experiments will be conducted here.
