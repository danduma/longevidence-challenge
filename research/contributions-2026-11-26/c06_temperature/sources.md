## Offline and public reproduction

Run `./run.sh`, or directly:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 verify.py
```

The verifier needs only this job directory. NumPy, pandas and openpyxl come from the shared scientific Python; pypdf 7.1.1 is vendored with its BSD redistribution license retained. Exact versions are in `results/environment.json`. No network requests or model calls occur during verification.

For public reproduction, acquire the workbook, deposited library, article HTML and author supplement from the URLs above and compare their SHA-256 against `inputs/manifest.json`. Downloaded filenames that contain PDFs/DOCX must pass content-type/magic checks: HTTP200 alone is not success. The numerical audit is implemented in `scripts/audit.py`, not in a downloaded notebook. The historical unfiltered CSV is simply the workbook sheet exported without filtering; all its 634×34 cells are reconciled against the workbook. The extra prior ledgers are local provenance comparisons and should be reacquired from the earlier release if an exact byte-level local replay is wanted. For an independent public reconstruction, use the original workbook/library as authorities and regenerate those derived CSVs; do not substitute new upstream contents while retaining old hashes. No claim is made that future live pages will be byte-identical to the pinned local HTML.

This deliverable remains a **local verification bundle**. No raw third-party input has been externally posted. Public code/results distribution should omit `inputs/` and full extracted source text unless each input's redistribution permission is identified. The original C06 code and derived numerical ratios may be shared with their source citations; pypdf must retain its bundled license.
