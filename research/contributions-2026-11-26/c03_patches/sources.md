## Public reproduction

The delivered pinned snapshots suffice: Python ≥3.11 with NumPy and SciPy plus a C++17 compiler. This run used the shared scientific interpreter. From this directory run:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 verify.py
```

Elsewhere replace the interpreter with a compatible local Python; `python -m pip install numpy scipy` supplies the two dependencies. No download is required for verification. If recovering primary sources, download the XML URLs above and the immutable Vitrify tree; check the included hash manifest. Europe PMC exports can change serialization over time, so retain the included exact snapshots for byte-level reproduction. `results/*.voxels.csv` and `*.patch.npz` are derived outputs; inputs to the executable are generated locally, hashed and removed after scoring. Run time is several minutes on this local CPU. `verify.py --resume` only rechecks cached voxel hashes and regenerates audit tables; the default performs fresh integrations.

The local public checkout's remote URL is not assumed here; provenance is given by the supplied workspace path, exact commit and file hashes. No repository publication or upload was performed.
