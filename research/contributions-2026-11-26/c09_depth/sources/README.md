Primary code/data snapshot: https://github.com/JeschekLab/ProtRec/tree/8b9a1865108fa44c3e0a24ac20a59754222847ca . `upstream_manifest.tsv` preserves the prior acquisition's exact URLs, Git blobs, SHA256 and sizes for upstream data and correction scripts. It is provenance, not an analysis instruction. `prior_reconstruction.json` and `prior_source_validation.json` describe the prior transformation/source reconciliation; C09 does not count their reproduction as a contribution. That reconstruction reproduced all deposited S8e AUCs. Its script05 table includes terminal235 labels; Fig.2 excludes them. C09 keeps them per frozen protocol.

Offline public reproduction of **C09** requires only this directory, including inputs/. Run `./verify.sh` or `C09_PYTHON=/path/to/python ./verify.sh` with the recorded dependency versions. No account, API, LLM or upstream reconstruction is required. `input_manifest.json` identifies every consumed byte snapshot and local origin; verification checks all hashes. Local origins are provenance references, not runtime dependencies. All scientific tables are re-created from snapshots; no prior result tables are used as labels or calculations.

For direct public download of the biochemical source, run `python -B download_source.py`. It downloads the exact raw GitHub file at the pinned commit, verifies Git blob 17a2b0225edafcda1fed7463161b4d8bb70389df and exact equality to the biochemical input; `live_download_check.json` records the successful live check. This optional command writes a new retrieval record. It is not needed by the offline verifier.

For primary DMS/control raw downloads, use the encoded `url` entries in upstream_manifest.tsv for Data_DMS_unmapped.txt.zip, Data_DMS_controls_unmapped.txt and TEVs_BCs_suspicious.txt, as well as scripts01.1–05. Public upstream tables are **not** interchangeable with the corrected C09 inputs. To rebuild those corrected inputs, apply the published min20DNA branch: remove author-flagged backbones, filter barcode depth20, pool counts, apply duplicate/outlier and positive-control exclusions, retain R rounding stages, and script05 single-mutant restrictions. The previous workspace reconstruction implementing this is research/millennium/agents/protease-corrected-sol/reconstruct.py (read-only original; hash below in evidence manifest). C09 supplies final corrected snapshots so verification does not depend on availability of that separate artifact. A fresh independent raw-to-corrected port is outside this contribution; its complete source reconciliation is prior work.
