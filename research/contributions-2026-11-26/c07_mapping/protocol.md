Suspect selection (union, no kinetic values used): (1) sequence length <400 aa; (2) normalized metadata species differs from normalized taxon_name; normalization collapses whitespace, lowercases and converts Unicode minus to hyphen only; (3) species contains cv., cultivar, strain, sp., subsp., var., PCC, or a digit. Keep every selected link in a ledger, including unresolved cases. Fetch all selected accession records, without selecting by kinetic outcome. Limited primary-assay retrieval prioritizes the <400-aa stratum then literal qualifiers; absent public text remains unresolved.

Primary comparison: released mapping versus conservative patch. A taxonomic correction requires a primary accession record documenting its organism and a primary assay establishing intended organism; no replacement accession is guessed. Quarantine when deposited sequence is a fragment (<400 aa), accession taxonomy conflicts without documented synonym resolution, or literal cultivar/strain identity lacks an exact accession-to-assay bridge. Length is an operational full-sequence eligibility threshold, not a claim that fragments are taxonomically false or biologically inactive. Maintain separate taxonomy and assay verdicts. Species-level agreement alone is not exact preparation/strain verification. Retain original accession and evidence; new sequence replacement only if primary records establish it.

Eligibility and impact: collapse exact duplicate metadata rows to unique species links for link counts; retain source observations independently as records, never biological replicates. Source eligibility: primary==1 and mutant==0 and whitespace-normalized species matches metadata. Report eligible source records, unique linked labels, and target-specific prediction records before/after quarantine. No kinetic target tuning, model fitting, or unavailable embedding reconstruction.

Exposure conventions fixed now: use released fixed prediction order and sklearn KFold(5, shuffle=True, random_state=0); preserve original folds after quarantine (no resplitting). A held-out row is exposed if another retained row in another fold has (a) same normalized species, (b) identical full released amino-acid string, or (c) same connected component linking exact sequences and base species (first two normalized whitespace tokens). Report counts with denominators and no independent-replicate inference. These are apparent reconstructed exposures, not recovered original fold manifests. No >=99% alignment or model performance claim.

Falsification: accession records may confirm all selected taxa and primary assays may identify exact strain/construct; then no new taxonomic repair is supported. Quarantine is supported only by explicit missing identity evidence or fragment eligibility. If patch removes zero additional links or offers only prior duplicate counts, contribution is unsuccessful. Any absent accession/text is a source-access failure, not a model refusal. No human expert review.
