# Conditioning the fitted mechanics map

The seven-block map removes the multi-MPa spikes seen on the original three-node cloud, but the graded versus uniform-strict ranking still reverses on refinement. This reversal holds on both the full cloud and the same retained interior support. Filtering the old fields alone favors graded at both levels, which would give the wrong coarse-mesh ordering for the regular re-solve.

## Controlled comparison

The baseline is the immediately preceding common-point benchmark. The old native cell-center scores already reversed between levels, and the two-node common cloud preserved that reversal for the hard peak alone. The full three-node cloud favored uniform strict on both levels. The new result is that a fixed-location mask favors graded at both levels, while the seven-block re-solve restores the reversal for both scores on either support. Its two-node cloud reduced the corner influence, but it changed both sample locations and quadrature weights. Here the three-node cloud is used twice on each solution, once in full and once after dropping points whose original cube-map Jacobian has a spectral condition number above 10. On the retained points the physical coordinates and relative weights are unchanged. This exploratory threshold was set before the re-solves. The mask covers high-condition regions along edges as well as at corners. It does not remove elements from the original solve.

The second intervention replaces the original mechanics map. Six curved face blocks connect an inner Cartesian box to the same analytic outer superellipsoid. In normalized coordinates each face direction \(v\) has one component equal to ±1 and the others in [−1,1]. The normalized position is \(s v\), where \(s=a+t(r-a)\), \(a=0.45\), \(r=1/\lVert v\rVert_p\), and \(t\) goes from 0 to 1. Neighboring faces agree along their shared rays, and the inner faces agree with the central Cartesian block. The shell Jacobian determinant in absolute value is \(4s^2(r-a)\) times the product of physical semiaxes. The bound \(r\ge3^{-1/p}>a\) and bounded derivatives on each closed block give uniformly invertible block maps. The fine mesh halves all three local element widths of the coarse mesh. The superellipsoid map adapts established radial meshing. A central cube joined to six cubed-sphere chunks also precedes this work in solid-Earth spectral-element mechanics. The experiment applies that geometry to the paired cryobag benchmark. [Calhoun, Helzel and LeVeque, Section 5](https://faculty.washington.edu/rjl/pubs/circles/SIR000723.pdf), [Komatitsch and Tromp, Figures 9–10](https://specfem.org/komatitsch.free.fr/published_papers/GJI1_2002.pdf), [Nowell map used by the baseline](https://mathproofs.blogspot.com/2005/07/mapping-cube-to-sphere.html).

Both map families receive the exact same 0.75 mm cut-cell donor histories, 0.30 s mechanics samples and schedule-specific −35 °C coldest-heart event. The fitted Maxwell law, stress-free start, three-point stiffness quadrature, phase-overlap transfer algorithm and the physical locations and constrained components of the six pinned degrees of freedom are held fixed. The overlap transfer is evaluated at orders 12 and 20. Each map has its own element-average temperatures, center history update and phase labels, so the experiment changes the mechanics discretization as a whole. Q1 stresses are evaluated at the same physical points, each strictly inside its owning element in all four meshes. The hard score is the sampled major principal stress maximum. The smooth score sums the exponential of all principal stresses on a 20 kPa scale, weighted by the normalized physical quadrature volumes, with equal weights across the same time samples. Lower scores are preferred. [Pinned Vitrify solver](https://github.com/Marc-Dvci/Vitrify/blob/1d498ee5c583e0112a762e60892d576ec2e27f57/tesseracts/mechanics/solver.py), [FEniCS discussion of DG0 ownership](https://fenicsproject.discourse.group/t/projection-of-dg0-function-over-non-matching-meshes/13810).

## Interpretation and scope

Joshi and Rabin use tensile principal stress on fitted cryobag models and carry the cooling and storage history into warming. This controlled test inherits the release-style stress-free start and uses the predecessor’s extended event horizon. Community discussion of uneven warming motivates the physical question but offers no evidence on this pair or either map. The immediately preceding audit connected high stresses to ill-conditioned locations. The paired ablation and remeshed comparison test how much of that observation survives on exactly the same physical sampling support. The retained mask is an attribution check on the original fields, and common-cloud scores are finite spatial samples. The point that maximizes a discrete stress can migrate between elements as the mesh changes. No biological fracture threshold is inferred. [Joshi and Rabin (2023)](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0290063), [CryoNet specialist archive](https://www.cryonet.org/cgi-bin/dsp.cgi?msg=18925), [predecessor report](sources/common-report.md).

## Reproduce

Run `python3 -B run_verification.py` from this directory. It uses the current Python interpreter and pip to install pinned binary wheels in a temporary directory inside this job, then runs the independent check. It requires access to PyPI and compatible wheels. With the pinned NumPy and SciPy already available, run `python3 -B verify.py` directly. The first attempt reached the coordinator with an interpreter that lacked NumPy. This command was tested with the coordinator’s default Python 3.15 on macOS arm64. The verifier uses the cached float64 thermal paths, reconstructs the cut-cell donor graph, reruns both families and both transfer orders, independently constructs the three-node cloud with an analytic baseline Jacobian, and evaluates pointwise stress with separately differentiated displacement basis functions and a separate exponential sum. It compares all scoring traces against results.json and the original full cube trace against the preceding independent archive. It checks the new analytic block Jacobians by finite differences including at block edges and corners. It also checks the early-window signs, the retained fraction of the original smooth sum, and the predicted smooth-score shift from renormalization in the regular solves. Both paths share the equilibrium solver and phase-overlap transfer. Use `python3 -B analysis.py` to regenerate results.json. If the thermal cache is absent, the same command regenerates it from the inherited thermal model. See [source provenance](sources/README.md).
