# Sources and solver attribution

The sources/upstream directory contains unmodified selected files from Vitrify by Marc Davici, pinned at commit 1d498ee5c583e0112a762e60892d576ec2e27f57. The original Apache 2.0 license is included. The analysis.py module reuses the independent NumPy/SciPy implementation from this coordinator's earlier cryo-objective-and-endpoint investigation. The solver reads the source geometry and released parameter vectors, then recomputes temperatures and stresses.

Paper XML copies retain original publisher, author, DOI and license metadata. Forum snapshots contain brief attributed excerpts and reading notes.
